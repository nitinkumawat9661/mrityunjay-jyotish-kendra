## Local preview

Run any static server from the repository root, for example:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Deployment

Import the repository into Vercel. No build command is required for this static site.

> Before running Google Ads conversion tracking, add the real Google tag / conversion ID supplied by the advertiser account. Do not invent IDs.
